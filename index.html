Google Calendar Sync

Auto-detect interviews from your Google Calendar.

1. Go to console.cloud.google.com
2. Create project → Enable Google Calendar API
3. Create OAuth 2.0 credential → Web Application
4. Add https://amaan-creates.github.io to Authorised JavaScript Origins
5. Add your email as a test user in OAuth consent screen
6. Paste Client ID below
